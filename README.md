# MoveMorelia

Prototipo interactivo de **MoveMorelia**, la app del transporte público de Morelia para estudiantes y trabajadores.

**Pruébala aquí:** https://adriangtzgnz-del.github.io/movemorelia/

Qué puedes hacer en la demo:

- Ver en el mapa los camiones, taxis y autos moviéndose en tiempo real.
- Saber cuánto falta para que llegue tu camión y qué tan lleno viene.
- Recibir avisos de retraso y de llegada.
- Comparar camión, taxi y auto con tiempo y precio.
- Usar el tutorial de bienvenida y el modo fácil con letras grandes.

Proyecto escolar de Tecmilenio Campus Morelia.
Equipo: Tyson, Adrián, Santiago, Victoria y María.

Los datos de la app son de ejemplo y sirven solo para mostrar cómo funcionaría.
